# 📈 MarketPredict — Stock Market Analysis & Prediction

MarketPredict is a **web-based stock market analysis and prediction platform**.  
It provides interactive tools to analyze stock data, visualize trends, and make predictions using **machine learning models**.  

The project combines a **Django backend** (for the website) with a **Streamlit dashboard** (for data analysis and predictions).

---

## 🚀 Features
- Clean and responsive **web interface** (Django + HTML/CSS)  
- **Interactive data visualization** (charts & graphs)  
- **Machine Learning models** for stock trend predictions  
- **Dual Interface**:  
  - Django site (for browsing and information)  
  - Streamlit app (for interactive predictions)  

---

## 🛠 Tech Stack
- **Frameworks:** Django, Streamlit  
- **Languages:** Python, HTML, CSS, JavaScript  
- **Libraries:** Pandas, NumPy, Matplotlib, Scikit-learn
